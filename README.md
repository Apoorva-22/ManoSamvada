# ManoSamvada

AI-powered mental wellness chatbot with emotion detection, crisis intervention, and admin analytics dashboard.

## Features
- User authentication
- AI chatbot conversations
- Emotion detection
- Crisis detection
- Session-based chat history
- User analytics dashboard
- Admin dashboard
- CSV export
- Keyword management

## Tech Stack
- Flask
- MySQL
- HTML/CSS/JS
- Groq Llama API
- Python

## Folder Structure
(routes/services/templates/static etc)

## Setup
pip install -r requirements.txt
python app.py

## Future Improvements
- Better multilingual models
- Fuzzy crisis detection
- Therapist integration
